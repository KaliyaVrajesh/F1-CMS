# Team Logos Directory
Store Formula 1 team badge & crest logos (.png, .jpg, .svg, .webp) in this directory.

### Naming Convention:
Files are matched by constructor ID or team slug:
- `red_bull.png`
- `ferrari.png`
- `mercedes.png`
- `mclaren.png`
- `aston_martin.png`
- `alpine.png`
- `williams.png`
- `rb.png` or `vcarb.png`
- `kick_sauber.png` or `sauber.png`
- `haas.png`
- `racing_point.png`
- `renault.png`
- `alphatauri.png`
- `toro_rosso.png`
- `alfa_romeo.png`
- `force_india.png`
- `lotus.png`
- `brawn.png`
- `benetton.png`
- `jordan.png`
